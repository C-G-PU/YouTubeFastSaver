# YouTubeFastSaver

A modern desktop application to download YouTube videos and music quickly, with support for built-in browser login, format selection, themes, and force downloading.

## Requirements

- Python 3.10+
- `ffmpeg` must be installed and added to the system PATH for audio extraction and video merging.

## Installation

```bash
pip install -r requirements.txt
```

## Running the App

```bash
python src/main.py
```

## Building the Windows Executable

Double-click `build.bat` or run it from the command prompt:

```cmd
build.bat
```

The compiled application will be located in the `dist\YouTubeFastSaver` folder.
